# 🍕 PizzaHub

🍕 *PizzaHub* is a modern and responsive pizza ordering website built using *React.js* ⚛️.

It provides users with a simple and enjoyable experience to explore pizzas, view details, add items to the cart, and confirm their orders. 🛒✨

---

## ✨ Features

🍕 Browse Popular Pizzas  
🛒 Add Pizza to Cart  
🔢 Increase / Decrease Quantity  
🗑️ Remove Items from Cart  
💰 Automatic Total Price Calculation  
📦 Order Confirmation  
📱 Responsive User Interface  
🎨 Clean & Attractive Design  
🧭 Navigation Between Pages
